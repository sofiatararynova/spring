# Лабораторная работа №1. Введение в Spring Boot

## Цель работы
Изучить основы создания веб-приложения на Spring Boot: работу с контроллерами,
шаблонизатором Thymeleaf, обработку форм и передачу данных между клиентом и сервером.

## Архитектура проекта
- **Стек:** Java 25, Spring Boot 4.1.1, Maven, Thymeleaf
- **Основные слои:**
  - Controller — обработка HTTP-запросов (`MainController`)
  - Model — класс предметной области (`Student`)
  - View — HTML-шаблоны Thymeleaf (`main.html`, `about.html`, `main-form.html`, `result.html`)
  - Стили — `src/main/resources/static/css/style.css`
- **Ключевые аннотации:**
  - `@SpringBootApplication` — точка входа
  - `@Controller` — контроллер
  - `@GetMapping` / `@PostMapping` — обработка GET/POST-запросов
  - `@RequestParam` — параметры строки запроса
  - `@ModelAttribute` — привязка формы к объекту

## Алгоритм работы
1. Главная страница (`/` или `/main`) — приветствие и описание работы.
2. Страница `/about?name=...` — информация об авторе.
3. Страница `/form` — форма ввода данных студента.
4. POST `/form` — приём данных через `@ModelAttribute`, вычисление группы
   по шаблону «ПИН-1» + две последние цифры года поступления и логина
   по шаблону «student-<группа>-<id>».
5. Страница `result` — вывод всех полей студента.
